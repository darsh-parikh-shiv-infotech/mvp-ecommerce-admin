# Frontend standards

- Name ordinary functions and function-valued helpers in `camelCase`. React components retain `PascalCase` names for JSX.
- Keep application-level routes, API endpoints, user-facing copy, fallback messages, and configurable values in [`src/utils/constants/constants.ts`](./src/utils/constants/constants.ts).
- Keep type/markup discriminants, algorithmic values such as indexes, and CSS/design tokens with the code or stylesheet that uses them.
- Run `npm run lint`, `npm run typecheck`, and `npm run build` before submitting frontend changes.
